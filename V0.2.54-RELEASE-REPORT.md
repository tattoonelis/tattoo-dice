# Tattoo Dice V0.2.54 — Canon manager

## Scope

- New internal route: `/canon/`
- Existing public root, public decks, Generator, Admin Ranking and animations remain unchanged.
- Source: `Tattoo_Dice_Classic_Deck_Rating_v2_Multi_Slot.xlsx`
- Canon baseline: 86 Excel subjects plus Dog as a separate Wolf-profile subject.

## Runtime tested

- Public `/` initializes at the iPhone viewport, Roll can be triggered and reports no browser console errors.
- Existing `/admin/` unlocks, initializes, shows the existing 782/1000 Classic progress and reports no browser console errors.
- `/canon/` unlocks and initializes at a 390×844 iPhone viewport with all seven subject groups accessible in the one-screen editor.
- Search and selection load Wolf and Dog with the expected profile.
- Dog and Wolf show matching active state, themes, Main/Detail slots, score 3, weight 12, family `wolf`, possibilities and Moon boost relation.
- Theme, slot, score, possibility and relationship controls are clickable multi-choice controls.
- Editing autosaves locally and survives a full page reload.
- Ranking and highlight CSV imports update subject history; a safe Canon JSON restore returns the baseline.
- Targeted three-dice and two-dice rolls force Dog into the result and accept ratings.
- Removing an existing subject produces a 10-roll regression queue and excludes that subject from generated tests.
- Classic export action executes and reports 141 slot records.
- No browser console errors were reported for Public, Admin or Canon.

## Statically checked

- All JavaScript entry files pass syntax validation.
- All JSON files parse.
- All HTML files have unique IDs and resolving local references.
- Canon contains 87 unique subjects, and every subject has at least one theme and one dice slot.
- Dog matches Wolf on active state, themes, slots, score, weight, family, possibilities and relations.
- Per-theme export preserves all 139 existing Classic runtime records and adds only Dog Main and Dog Detail, for 141 Classic records.
- Theme export filters by exactly one theme and retains the existing runtime deck schema.
- Public root, public Classic/Fantasy decks and all existing Admin HTML/CSS/JavaScript files are byte-identical to V0.2.53.
- Netlify routing and no-index headers include `/canon/` without changing existing routes.
- Supabase upsert/read logic and `canon/setup.sql` match the existing REST architecture.

## Not runtime tested

- Cross-device Canon sync was not executed because `canon/setup.sql` has not yet been run in the live Supabase project. Local autosave and restore were runtime tested.
- App Store purchase validation and paid-deck delivery are not part of this web-admin release. The per-theme JSON separation is ready for a later authenticated purchase/download layer.
