# Tattoo Dice V0.2.59 — public theme locks

## Result

Canon is now the single theme switchboard for the public Live App as well as the two unrestricted admin tools. Creating a theme automatically makes it visible in Live but keeps it locked until it is deliberately released from Canon.

## Public access behavior

- Classic is permanently public.
- Fantasy remains locked by default and retains its existing tester PIN `2311`.
- Every other newly created theme is locked by default and has no public bypass code.
- Canon provides one explicit public-status button per theme.
- Testversie and Ranking ignore the public lock and can always use every Canon theme.

## Lock enforcement

Live refreshes the theme catalog on startup, on window focus or visibility return, when the theme menu opens and after every completed roll. The check is deliberately performed after the dice animation so it adds no network wait before normal rolls.

When a theme is locked during an active roll, the current animation and result finish normally. The refreshed lock is then cached and the next roll is rejected immediately, with the theme menu opened so the user can select an available theme.

## Storage and compatibility

The `publicUnlocked` flag is stored in the existing `__themes` payload inside `canon_subjects`. No table, SQL migration or Supabase dashboard change is required. Catalogs created before V0.2.59 remain compatible: Classic defaults to public and themes without an explicit flag default to locked.

The bundled Classic and Fantasy JSON files remain safe deck fallbacks. New themes load from their Canon-published `__deck_<theme>` record.
