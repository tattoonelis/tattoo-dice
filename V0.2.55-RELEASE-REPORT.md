# Tattoo Dice V0.2.55 — Canon landscape sheet

## Scope

- Reworked only the isolated `/canon/` route and its documentation.
- Existing Public, Generator, Admin Ranking, public deck JSON and animations are unchanged.
- Source remains `Tattoo_Dice_Classic_Deck_Rating_v2_Multi_Slot.xlsx`.
- Baseline remains 86 Excel subjects plus Dog as a separate Wolf-profile subject.

## Canon workflow

- Select Classic or Fantasy at the top.
- Search or add a word.
- Choose Score 0–3; Weight follows automatically.
- Toggle Main, Detail and Effect independently.
- Select an existing Family or type a new Family.
- Add an optional note.
- Changes save locally immediately and sync to Supabase when available.
- Export only the selected theme as runtime JSON, or make a full safety backup.

## Testing boundary

Canon no longer contains any combination-testing queue or ratings. All testing remains in the unchanged `/admin/` page. When a real new theme is added, its words are curated here and its combinations are tested through Admin Ranking.
