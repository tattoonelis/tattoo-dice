# Tattoo Dice v2.53.2 — correction and test report

## Scope

This release changes only:

- Previous Roll discovery and touch/drag reliability.
- Menu/Main close-control placement.
- THEME/selection grouping.
- AI Image Generator layout, controls and visual treatment.

Dice visuals, roll timing, Shake to Roll, Main VFX, shadows, canonical
composites, deck data and counter behavior were not redesigned.

## Runtime tested in the in-app browser

- Startup and loading complete without console errors.
- Random starts with three dice.
- 1 → 2 → 3 transitions complete and the selected control stays synchronized.
- A fixed Main can be selected and disables the one-die option.
- RESET returns directly to Random with three dice.
- ROLL completes.
- The first settled Roll displays the short Previous Roll hint for ten seconds.
- Dragging the settled dice to the right restores the previous three subjects.
- The Previous Roll frames retain their original aspect ratio without stretching.
- Drop/Fall snapshot frames use the same aspect-ratio-preserving rendering.
- The favorite heart remains an overlay and is positioned one control-height lower.
- Menu opens; THEME sits above its selector inside one grouped component.
- Menu and Main close controls render outside the panel boundary.
- Favorites opens as a full page and BACK TO DICES returns home.
- AI Image opens as a full page with three bottom controls.
- The generator window is at least as wide as the complete three-button row and
  remains visibly lighter than the surrounding app background.
- AI generation locks Back and Save, reaches and pauses at 89%, then completes.
- At 100% the status reads IMAGE FINISHED.
- The favorite selector is replaced in-place with I’LL DRAW IT MYSELF.
- Back and Save are enabled after completion.
- The iPad portrait layout was checked at 768 × 1024 with no horizontal overflow.

## Static validation

- Main JavaScript syntax: valid.
- Expansion JavaScript syntax: valid.
- JSON files: valid.
- Duplicate HTML IDs: none.
- Local asset references: checked.
- ZIP integrity: checked after packaging.
