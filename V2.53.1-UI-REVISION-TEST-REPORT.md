# Tattoo Dice v2.53.1 — UI Revision and Test Report

## Scope

This revision continues from the verified v2.53.0 UI expansion. The dice
engine, Roll/Shake motion, Main VFX, shadows, canonical 1/2/3 composites,
Previous Roll memory and result generation were not redesigned.

## Home

- The Favorite heart is an absolute overlay inside the dice viewport.
- It no longer participates in the Home grid and cannot push the controls
  toward the counter.
- Short and regular phone layouts keep a clear gap between controls and footer.

## Menu and Main

- The Menu popup uses the same blue material as the Home Menu button.
- The Main popup uses the matching green Main material.
- Repeated MENU and MAIN headings were removed.
- Theme, Menu links and Main choices now share one typographic scale.
- Theme arrows only preview a theme.
- A theme is activated only by tapping the centre theme field.
- Locked Fantasy is displayed as `FANTASY 🔒`; the PIN screen opens only after
  tapping that selected centre field.

## Favorites page

- Favorites is a full app page, not a modal or submenu.
- It reuses the original background, footer and credit position.
- The footer counter reads `N TATTOO IDEAS SAVED`.
- The feature header is half-height, drops into place and has a blue aura.
- Home Menu/Roll/Main and utility controls are absent on this page.
- Bottom controls are `BACK TO DICES`, `REMOVE FAVORITE` and `THEME: …`.
- Internal technical `TD-…` identifiers are no longer rendered.
- Cards underneath the active card remain fully opaque.
- Placeholder hearts are larger, red and contain white subject text.
- Existing pointer-based left/right card navigation and local Favorite storage
  remain intact.

## AI Image Generator page

- AI Image Generator is a full app page using the original footer and rolled
  counter position.
- Its half-height feature header drops in with a blue aura.
- The two-column Favorite selector occupies the left two control slots and the
  plasma-style Generate button occupies the right slot.
- Generation status appears at the upper-left of a dedicated generator window.
- Progress is monotonic and deliberately pauses at 89%.
- At 80% the clown starts appearing heavily blurred.
- At 100% the blur clears and the artwork pops into focus.
- The complete text bubble drops from above and lands just above the generator.
- The easter egg remains entirely local: no AI service, network request,
  tracking, account or extra storage was added.

## Runtime checks performed

- Fresh splash/startup at 390×844.
- Home at 390×844 and a short 390×667 browser viewport.
- Home controls remain above the footer in both viewports.
- Menu opens with blue styling and normalized typography.
- Theme arrow preview does not open PIN.
- Tapping the previewed locked theme opens PIN.
- Main opens with green styling and normalized choices.
- Favorites opens as a full page and returns cleanly to Home.
- Favorites counter/ARIA label changes to saved count and restores on exit.
- Technical card code is absent.
- Two-card left swipe changes the active Favorite.
- AI page opens at regular and short phone heights.
- AI progress pauses at 89%, shows blurred artwork from 80%, clears at 100%,
  drops the message bubble and exposes the final exit.
- Roll lands normally after returning from feature pages.
- 3 → 1 → 3 transitions complete.
- Fixed Main still disables the one-die selector.
- Reset returns to Random and three dice.
- No browser runtime errors or warnings were recorded during these checks.

## Static checks

- `script.js` and `expansion.js` syntax.
- All JSON deck and manifest files parse.
- HTML IDs are unique.
- Required local entry files exist.
- ZIP contents and archive integrity are checked before delivery.

## Hardware-only limitation

Physical DeviceMotion input cannot be generated by the desktop browser. The
existing Shake sensor engine was not modified by this UI revision.
