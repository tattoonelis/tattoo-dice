# Tattoo Dice V0.2.56 — shared ranking intelligence

## Scope

- Started from the complete V0.2.55 project: V0.2.53 Public/Admin plus the V0.2.55 Canon route.
- Preserved the current illustrated public and Admin logos and the complete V0.2.53 Admin Ranking layout.
- Added no new management app, category or morph property.

## Shared generator

Public, `/generator/` and `/admin/` now use `shared-generator.js` for:

- Main / Detail / Effect planning;
- explicit weights with score fallback;
- exact duplicate prevention;
- family exclusion;
- `requires`;
- `blockedWith`;
- Detail/Main slot fallbacks;
- relationship-aware weighted selection.

Admin Ranking therefore tests the same selection rules used by Public and Generator.

## Ranking behaviour

- Reads H*LL YES, MEH and F*CK NO evidence per unordered word pair.
- Requires at least three observations before a relationship can affect selection.
- Uses eight baseline-equivalent prior observations to prevent small samples from taking over.
- Weak relationships receive a soft multiplier down to 0.35 per pair.
- Strong relationships receive a deliberately small bonus, capped at 1.15 per pair.
- Combined influence on a candidate is capped between 0.20 and 1.25.
- Individual subject weights remain unchanged.
- No rating automatically creates a hard block; existing canon rules remain the only hard blocks.
- Admin rebuilds the model after each save. Public and Generator reload it on startup and theme changes.
