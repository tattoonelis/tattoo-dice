# Tattoo Dice V0.2.60 — native Admin Live and continuous content sync

## One Live App

The Admin Panel now opens Live through `/admin/live/`. This is a full-screen shell around the exact public root app, not a copied generator. It keeps the experience inside the installed Admin PWA and adds only a fixed return route to the Admin home.

## Public synchronization

Every Live session reads the shared Supabase Canon deck and ranking relationship model:

- at initial startup;
- when changing theme;
- when the browser or installed app regains focus;
- at least every 60 seconds while visible;
- after a completed roll when the previous full refresh is at least 30 seconds old.

The lighter theme-access request still runs after every single roll, so remotely locking a theme always stops the following roll. The throttling applies only to the larger Canon and Ranking refreshes and avoids downloading the complete ranking history unnecessarily on rapid consecutive rolls.

Temporary background network failures preserve the last successfully loaded relationship model. The bundled JSON deck remains the Canon fallback.

## Automatic Main selection

The Main selector is rebuilt from the current published deck after each full synchronization. A subject appears only when it has:

- slot `main`; and
- score exactly `3`.

Consequently a new score-3 Main appears without a code release. Lowering it to score 2, removing its Main slot, disabling it or removing it from the current theme removes it after synchronization. If that subject was fixed as the selected Main, Live resets the selection to Random.

## Deployment

No Supabase migration is required. Deploy the complete V0.2.60 site package so `/admin/live/`, the updated public script and the refreshed Admin service worker are released together.
