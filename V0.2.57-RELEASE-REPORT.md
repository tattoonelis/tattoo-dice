# Tattoo Dice V0.2.57 — live Canon decks

## Outcome

Canon is now the live source for word availability and deck metadata. Each save publishes the currently selected theme as the complete runtime JSON structure inside the existing Supabase `canon_subjects` table. No additional Supabase table or migration is required beyond the existing Canon setup.

## Runtime flow

1. Canon immediately saves the edited subject locally.
2. After the existing 650 ms debounce, the subject is saved to Supabase.
3. Canon rebuilds the complete selected-theme deck and upserts it as `__deck_<theme>`.
4. Public, `/generator/` and `/admin/` load that complete published deck.
5. If Supabase is unavailable or no published deck exists, the bundled JSON is used unchanged.

Already-open generator pages refresh Canon when the page becomes visible or focused again. This covers the normal workflow of editing Canon and switching back to the generator without adding continuous polling traffic.

## Rule preservation

- The published deck contains Word, Score, Weight, Slot and Family exactly like the bundled JSON.
- Hidden `blockedWith` and `requires` arrays are retained.
- The Wing exclusions for Butterfly, Eagle, Parrot, Raven and Swallow remain active.
- Ranking-derived relationship multipliers continue to run after the Canon deck is loaded.
- Canon does not create or remove ranking relationships.

## Family cleanup

The family picker is calculated only from active subjects assigned to at least one theme. Once the final active subject is moved out of an old family, that unused family disappears from the picker automatically. Used families are never merged automatically.
