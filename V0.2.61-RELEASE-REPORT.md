# Tattoo Dice V0.2.61 — independent themes and Fantasy workspace

## Canon V3

Canon now stores one shared subject identity with an independent profile per theme. Each profile owns score, automatic weight, Main / Detail / Effect slots, family, notes, hard blocks and requirements. Existing V1 and V2 local or cloud payloads migrate at load time; the existing `canon_subjects` table remains sufficient.

When a new theme is created, selected words copy their current Classic profile once. The copy then becomes independent. Editing Wolf in Fantasy therefore no longer changes Wolf in Classic.

## Fantasy word-only import

The supplied Fantasy PDF produced 147 unique word names. PDF ratings, weights, slots, families and notes are ignored.

- Exact matches against the current Classic Canon copy the complete Classic profile.
- New names start with score 0 and automatic weight 0.25.
- New names have no slots, no family, no notes and no rules.
- No family is generated from the word name.

In the current cloud-backed Canon test, 54 names matched Classic and 93 remained new/incomplete. Matching happens after the current cloud Canon loads, so later Classic additions such as Cloud are inherited correctly.

## Safe incomplete state

Incomplete words are visible and editable in Canon with an `UNASSIGNED` family state. They are not included in the published deck until they have at least one selected slot and a family. Consequently unfinished preparation cannot enter Generator, Ranking or Live.

The first edit that completes a word publishes the updated theme through the existing Canon publication flow. Public and internal clients continue reading the generated `__deck_<theme>` snapshot.

## Interface

- Admin's four tool cards are vertically centered and the redundant Admin Panel heading is removed.
- Canon's cropped top-left logo is removed.
- Canon remains visible in narrow portrait browser panels and scrolls the table horizontally.
- Every theme shows its own direct OPEN / LOCK control. Classic is permanently open.

## Deliberately deferred

The visual public lock is not yet a purchase-grade entitlement system. Authenticated purchases, event codes, promotions and server-enforced deck access remain planned for a later release. The independent `theme + subject` profile model introduced here is compatible with that future work.
