# Tattoo Dice V0.2.53

## Structure

- `/` — approved public v2.52.24
- `/generator/` — current development build with Favorites and Generator
- `/admin/` — existing Admin interface
- `/admin/test/` — existing Admin Test interface

## Access

`/generator/` uses the same six-digit PIN as Admin and Admin Test.
It is also marked `noindex, nofollow, noarchive` in the page metadata and
through the Netlify headers configuration.

## Runtime tested

- Public `/` loads as v2.52.24.
- Public `/` contains no Favorites or Generator interface.
- Public Roll completes and updates the counter.
- `/generator/` opens on the six-digit PIN gate.
- An incorrect PIN is rejected.
- The shared correct PIN unlocks the development app.
- Roll completes inside `/generator/`.
- Switching between two and three dice completes and returns to the correct state.
- The Generator page opens and returns to the dice screen.
- No browser console errors were reported on either route.

## Static checks

- Public `index.html`, `style.css`, `script.js`, manifest, decks and primary
  artwork are byte-identical to the supplied v2.52.24 source.
- All seven JavaScript entry files pass syntax validation.
- All eight JSON files parse successfully.
- All four HTML files contain no duplicate IDs.
- All local HTML file references resolve.

## Important

This is a preview release. It remains V0.2.53 until the product owner explicitly
approves the public V1.0.0 release.
