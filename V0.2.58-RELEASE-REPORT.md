# Tattoo Dice V0.2.58 — unified Admin Panel

## Admin structure

- `/admin/` — central Admin Panel, version V0.2.58.
- `/admin/generator/` — Testversie, preserving the complete Generator preview.
- `/admin/ranking/` — the existing ranking workflow and progress.
- `/admin/canon/` — Canon word, family and theme management.
- `/` — the unchanged public Live App, linked from the Admin Panel.

The Admin Panel unlock is shared for the current browser tab session. Each internal tool includes a fixed button back to the panel. Old `/generator/`, `/canon/` and `/admin/test/` addresses redirect to the appropriate new location.

## Self-service themes

Canon includes `+ THEME`. Creating a theme opens a dedicated picker containing only the existing word names. The curator selects the desired words; Canon then assigns the new theme to the existing subjects, automatically retaining:

- score 0–3 and calculated weight;
- Main, Detail and Effect eligibility;
- family;
- notes;
- hidden `blockedWith` and `requires` metadata.

The theme catalog is stored as `__themes` in the existing Supabase `canon_subjects` table. No Supabase migration or additional table is required. New themes become available automatically in Admin Testversie and Ranking. They are not exposed automatically in the public Live App.

## Live data separation

- Canon controls which subjects and profiles are available per theme.
- Ranking controls relationship probabilities between selected subjects.
- The public Live App keeps its current interface and theme availability, while existing published theme values and relationship data continue to update live.
- Bundled JSON files remain the offline/error fallback.
