# Tattoo Dice v2.54 — Simple Heart + Synchronized Previous Roll

## Implemented

- Replaced the experimental arrow animation with one small Instagram-style heart.
- Heart sits in the free space between the header and the upper edge of the
  right support die in the three-dice composition.
- Its right edge aligns exactly with the right edge of the green Main button.
- Empty state uses a 70%-opaque light outline.
- The control is fractionally smaller than the earlier heart.
- Saved state uses a solid red fill.
- No flight, impact, pop, pierced-heart or aura animation remains.
- Rebuilt Previous Roll as one shared two-panel track:
  - current dice move right;
  - previous dice enter from the left;
  - both panels always use the exact same transform, distance and speed;
  - a completed swipe restores the previous roll;
  - a short swipe returns both panels to their starting positions.

## Runtime tested in the in-app browser

- Startup/loading completes.
- No horizontal overflow in the phone layout.
- Heart toggles from light outline to solid red and back.
- No arrow or reward-animation element is created.
- Roll completes and releases the controls.
- Completed right swipe restores the previous result.
- Short right swipe snaps back without changing the result.
- The shared swipe track is removed cleanly after both outcomes.
- Dice count transitions 3 → 1 → 2 → 3 complete.
- Fixed Main selection completes and returns cleanly to Random.
- No console errors or warnings were present before the final isolated UI changes.

## Statically checked

- Main and expansion JavaScript syntax.
- JSON parsing.
- Required local asset references.
- ZIP integrity.

## Hardware-only exception

- Physical Shake to Roll sensor input cannot be generated by the desktop browser test. Its code and UI were not changed in this release.
